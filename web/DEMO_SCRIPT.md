3. Wait for response

**"Notice what happened:"**
- ✅ Voice was recognized and converted to text

## 🎯 Demo Tips

### Before Demo
- [ ] Test internet connection
- [ ] Open app in Chrome browser
- [ ] Test microphone permission
- [ ] Have backup questions ready
- [ ] Clear browser cache if needed

### During Demo
- Speak clearly and slowly for voice input
- Show enthusiasm about voice feature
- Highlight multi-language capability
- Emphasize farmer-friendly design
- Keep moving - don't wait too long for API

### If Something Fails
- **Voice not working**: Switch to text input, explain browser compatibility
- **API slow**: Explain free tier hosting, show cached response
- **Weather not loading**: Explain demo mode, focus on UI

### Energy & Presentation
- Smile and make eye contact
- Use hand gestures to point at screen
- Vary your tone - excitement for innovations
- Pause after key points
- End with confidence

## 📝 Q&A Preparation

### Expected Questions

**Q: How did you train the chatbot?**
A: "We integrated with a RAG model API that's trained on verified farming datasets. It uses retrieval-augmented generation to provide accurate, context-aware answers."

**Q: What if the farmer doesn't have internet?**
A: "Currently requires internet, but we're planning an offline mode with cached common questions and answers. The crop calendar can work offline."

**Q: How do you ensure answer accuracy?**
A: "The RAG model provides confidence scores. We can add a feedback mechanism for farmers to rate answers, continuously improving accuracy."

**Q: Can you add more languages?**
A: "Absolutely! The architecture is designed for easy language addition. We can add any language supported by Web Speech API."

**Q: What about farmers without smartphones?**
A: "We're starting with smartphones as they're increasingly common. Future versions could include SMS-based access or USSD codes."

**Q: How will you monetize?**
A: "Free for farmers. Potential revenue from agricultural companies for targeted advice, government partnerships, or premium features for agribusinesses."
